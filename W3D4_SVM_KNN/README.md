# W3D4: SVM & KNN — When to Use What

## Objective

The objective of this task is to implement and compare SVM and KNN classification models and understand the effect of hyperparameter tuning. Random Forest was also implemented to demonstrate ensemble learning and feature importance.

## Dataset

The Iris dataset from Scikit-learn was used. It contains 150 samples with four numerical features and three target classes.

## Models Implemented

- Support Vector Machine (SVM)
- K-Nearest Neighbors (KNN)
- Random Forest Classifier

Feature scaling was applied to SVM and KNN using StandardScaler.

## Hyperparameter Tuning

GridSearchCV with 5-fold cross-validation was used to tune SVM and KNN parameters.

## Feature Importance

Random Forest feature importance was extracted and visualized to identify the most influential features.

## Conclusion

SVM and KNN were implemented and compared using the same train-test split. Hyperparameter tuning was used to improve model selection. Random Forest was additionally used to demonstrate ensemble classification and feature importance.
